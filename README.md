# 💾 3D Disk Drive

**Realistic 3D floppy / CD / DVD disk drive emulator** in the browser.

Spinning animations · File explorer feel · Retro computing vibes

[![Demo](https://img.shields.io/badge/Live%20Demo-00ff41?style=for-the-badge&logo=vercel&logoColor=white)](https://github.com/sayan9168/3D-Disk-Drive)
[![Stack](https://img.shields.io/badge/Stack-HTML%20%2B%20CSS%20%2B%20JS-blue)](#)

---

## Features

- 3D-style disk drive visualization
- Floppy / CD / DVD mode aesthetics
- Spinning disk animations
- File explorer style interaction
- Matrix / retro visual effects
- Pure frontend — no backend required

---

## Run locally

```bash
git clone https://github.com/sayan9168/3D-Disk-Drive.git
cd 3D-Disk-Drive

# Open in browser
open index.html
# or serve:
npx serve .
```
